# APB＋割り込み：仕様変更の演習用仕様

対象は既存のAPBレジスタと4要因の割り込み回路です。CONFIG下位4ビットでIRQを許可し、PENDINGは許可と独立にイベントを保持します。PENDINGはオフセット8のW1Cです。同期リセット、正常／エラー応答、待ち、読出しの時点は元のAPB例に従います。

- **S-R1**：r1は、正常完了したW1Cとイベントが同じエッジで重なったビットを1にする。セット優先。
- **S-R2**：r2は、そのエッジの対象W1Cビットを0にする。クリア優先。イベントだけなら1、クリアだけなら0、どちらもなければ保持する。

変更するのは、この競合時の優先順位です。r2を製品一般のW1C仕様とする意図はありません。両版で同じ待ち構成・seed・入力列を使い、期待値を仕様に合わせて変更します。r1の成功をr2へ移すことも、r1チェッカーの失敗をr2の回路不具合と即断することもしません。

機械照合の対象は各版の変更要求1件です。4要因×マスク0／1の8つの競合条件を、wait=0／1／3で独立に要求します。他の動作は既存テストベンチの全サイクル比較を保持しますが、元の全要求カタログ・クロスモデルをr2で再承認した結果ではありません。
