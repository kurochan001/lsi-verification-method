# シリアルフラッシュの書込み許可・消去境界・タイムアウトを検証する

16バイトのNORメモリを持つ模擬デバイスに、コントローラがシリアルでコマンドを送ります。書込み前の許可、送信ビット列、ステータスのサンプリング、読出しデータ、XIP窓から見える内容を独立に照合します。コマンド番号・アドレス幅・ステータス転送はこの教材用に定義しています。

## 回路の契約

ホストはアイドル時に `go` を1サイクル立て、コマンド、8ビットアドレス、1バイトのデータを渡します。転送中は入力を書き換えても、受け付けたフレームが最後まで送られます。完了を `done`、拒否・タイムアウトを `err` の1サイクルパルスで報告します。

| コマンド | シリアルで送るバイト（送信順） | 完了時の状態 |
| --- | --- | --- |
| 読出し `03` | 03、アドレス、00、00 | 第3バイトの返答のbit 0が状態、第4バイトがデータ。状態が1ならエラー。読出し値を保持 |
| 書込み許可 `06` | 06 | `wel` をセット |
| プログラム `A0` | A0、アドレス、データ | 指定した1バイトの1→0書込み。許可を消費し、正常なら4回のビジー応答 |
| セクタ消去 `32` | 32、アドレス | アドレスを含む4バイト区画をFFに戻し、6回のビジー応答 |
| 全消去 `D8` | D8 | 全16バイトをFFに戻し、6回のビジー応答 |
| 障害解除 `C7` | C7 | ラッチした障害を解除。障害があれば4回のビジー応答 |

未定義コマンド、および `wel=0` でのプログラム・消去はCSを駆動せず拒否します。正常に送った `06` 以外のフレームで許可が消費されます。禁止した0→1書込みや範囲外への書込みではメモリを保持し、解除まで障害を記憶します。XIP窓はアイドル時に入力アドレスの値を返し、同時に入力されたコマンドは受け付けません。範囲外の読出し値および転送中のホスト読出し値はFFです。

`div1` と `div4` ではSCLKの半周期をそれぞれ1、4入力クロックにします。CSは負論理でSCLKは通常Low、MSBから送信し、立上りで取り込み、立下りで次ビットに移ります。更新コマンドの後はCSを1入力クロック解除してから再選択します。この待機区間ではSCLKをLowに保ち、1ビット周期ごとにMISOのビジーレベルをサンプリングします。6回ビジーでも7回目が0なら成功し、7回目も1ならエラーです。リセット時には転送を中断し、模擬メモリをアドレスとA0の排他的論理和で初期化します。

## 期待値と検出

[Pythonモデル](run.py)が命令単位でバイト配列、許可、障害、シリアルフレーム、許される待ち時間を計算します。[テストベンチ](tb/flash_tb.sv)は各入力クロックで実ピンのCS・SCLK・MOSIを調べ、MISOがクロックHigh中に安定していること、および応答と許可を確認します。[模擬デバイス](rtl/flash_model.sv)はピンから受け取ったビットだけで動作します。セクタ消去後は隣接区画を含む全アドレス、全消去後は各バイトのシリアル読出しを照合します。

| 変異 | 観測する失敗 | ラベル |
| --- | --- | --- |
| 1 | 許可なしでプログラムのCSが下がる | FLASH_CTRL |
| 2 | 消去の6回目のビジーで早期終了 | FLASH_CTRL |
| 3 | プログラムのデータだけLSBから送信 | FLASH_DATA |
| 4 | ビジー解除のサンプルでもWIP表示が残る | FLASH_STATE |

[要求カタログ](requirements.json)は4要求・14目標です。固定58操作に、smokeは乱数20操作×1 seed、nightlyは100操作×3 seedを加えます。乱数操作には必要に応じて許可とXIP読出しが付くため、実際のベクトル行数はseedごとに変わります。

## 実行

```sh
python3 examples/local-flash-ctrl/run.py --out artifacts/flash-ctrl-smoke
python3 examples/local-flash-ctrl/run.py --profile nightly --out artifacts/flash-ctrl-nightly
python3 -m unittest discover -s examples/local-flash-ctrl/tests -v
```

2026-11-23にPython 3.14.7とIcarus Verilog 14.0開発版で、両構成のsmoke 12件とnightly 16件が成功しました。各構成で14/14目標に到達し、4/4変異を検出しました。セルフテストは9件です。確認範囲は命令当たり1バイトのプログラム、2つの分周値、この16バイトモデルの論理動作です。実フラッシュのページ折返し、物理的な不揮発性・耐久性、製品固有の命令には別の検証が必要です。
