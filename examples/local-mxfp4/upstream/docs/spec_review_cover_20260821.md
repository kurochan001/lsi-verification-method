## 各文書の要旨

### Rev.1.3 本文 — 段階 7 を全項目実装した結果

| # | 節 | 内容 | 重み |
|---|---|---|---|
| D1 | 7.7 | 「統計的に**正方向へ**偏る」は符号が逆。クランプは大きさを必ず縮めるので偏りは原点方向 (負) に出る。実測でも大きさの偏りは -4.7 % | 中 |
| E1 | 6.3 | gradual underflow で acc がデノーマルになったら、加算器へ渡す前に正規化が要る (5.6 節の指数比較が [1,2) 正規化を前提としているため)。実際に踏んで結果が壊れた | 補足 |
| E2 | 5.7 | near path は必ず実効減算なので LZA は減算専用の式で足りる。加算も扱う一般形を持ち込むと桁落ちの大きいケースで 6bit ずれる | 補足 |
| E3 | 3.3 | ready を追加すると 9.5 節の `p_latency` はそのままでは成立しない。`iff in_ready` 修飾が要る。AXI §A3.2.1 の組合せパス要件から入力 FIFO の必然性も添えると伝わる | 補足 |

段階 7 の 4 項目 (3.3 / 5.7 / 6.3 / 7.7 節) はすべてパラメータ切替で実装済みで、
**既定値は Rev.1.3 の規範どおり**です。既定のままなら段階 6 までのビット一致回帰は
1 ビットも変わりません。

### 付録B — マルチ精度拡張 (FP16 / MXFP8 / MXFP4)

2026-08-21 に受領した草案です。**数値主張と骨格コードを機械抽出して動かしました。**
B.2 の E4M3 統一表現 (全 256 コード)、B.6 の s42 固定小数点の幅の導出と指数定数
sa + sb − 272、B.7 の FP16 exact 積の指数式 (20 万ペア) は、いずれも独立に組んだ
リファレンスと一致しています。

| # | 節 | 内容 | 重み |
|---|---|---|---|
| B-1 | B.10 | 「e_rel ≤ −10 は 0 へ丸める」の境界が 1 binade ずれている。e_rel = −10 はタイ点のみ 0 | 高 |
| B-2 | B.10 | RNE の 3bit 一般式が subnormal 域 (代表点 4 / 2 / 1 点) を扱えない | 高 |
| B-3 | B.9 | `$past` の第 1 引数が部分選択の式。本文 10 章 運用ノート第四点に反する | 中 |
| B-4 | B.7 | `pack_fp32` が本文 5 章と同名で引数の意味が違う | 低 |
| B-5 | B.9 | SVA が未定義の識別子を参照 | 低 |

**B-1 と B-2 はどちらも E4M3 の subnormal 域**で、本文 7.2 節が E2M1 について
明示している論点 (e_rel = −1 の binade は代表点が 0.5 のみ) の対応物が抜けている、
という同じ形です。E2M1 で確定表を置いたのと同様、**subnormal 域を含む確定表**を
用意していただけると実装側は迷いません。

方針そのもの (案A、後段共有、s42 固定小数点、FP16 の exact 積) には異論ありません。
