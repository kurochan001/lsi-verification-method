# 割り込みコアの教材仕様 r1

S01：入力は立下りで安定させ、立上りで受理する。リセット解除中、イベントとクリアの同時受理ではセットを優先し、PENDを1にする。

S02：リセット解除中、イベントだけを受理するとPENDを1にする。IRQ_ENは保持状態の更新を抑止しない。

S03：リセット解除中、クリアだけを受理するとPENDを0にする。

S04：リセット解除中、両操作がなければPENDを保持する。

S05：Low有効の同期リセットを取り込むとPENDを0にする。他の操作より優先する。

S06：IRQはPENDとIRQ_ENの論理積とする。状態更新のSVAは次の立上りのサンプルで結果を確認する。

この仕様は既存の割り込みSVA例へ合わせた教材です。バス受理パルスの生成、X/Z、グリッチ、物理タイミングは対象外です。
