## 作業中に起きたこと

- g02の作成担当が、テストを書くスクリプトで既存のテスト`tests/ch7/test_illegal_iterator_argument_without_with.sv`を上書きしました。
  - 作成担当が`git show HEAD:`で元に戻しています。統合前に、追跡済みのファイルに変更がないことを確かめました。
  - 以後、そのスクリプトは既存のファイルを上書きしないように直されています。
- g02の作成担当は、規格の解釈の論点を1つ報告しています。
  - 6.24.3はクラスをビットストリーム型に含め、`longint'(this)`のような形を例として挙げています。
  - 一方、8.28はクラスのハンドルを他の型へキャストできないとしています。
  - 今回のテストは6.24.3の例の形だけを合法としています。既存の`tests/ch8/test_illegal_cast_class_handle_to_integral.sv`は8.28の側に立っています。
